# 兼容与验证说明

公开文档包含 60 组 API。剔除一个普通“Parameters”段标题后，共 731 个公开成员。当前检查显示 731 个都有对应入口；这包括可读属性和可调用方法，不意味着每项原生行为已获真机验证。

| 范围 | 实现 | 需要注意 |
| --- | --- | --- |
| JavaScript、文件、模块、数据、密钥 | 同一隔离 Worker；私有文件、脚本映射、持久 metadata、Android Keystore | 保存脚本以 JSON 仓库为主，运行器提供源码路径映射，必要时物化文件；有资源上限 |
| 绘图、路径、图片、渐变、字体 | 安卓 Canvas/Bitmap + 同步分段通道，预览使用相同配方的 Canvas | 字体由安卓提供，PNG/JPEG 会真实转换，JPEG 使用白色透明底替代 |
| 日期、XML | 安卓 ICU 与 JS 事件解析 | 浏览器的日期解析只支持常用格式；安卓 ICU 支持完整模式 |
| 定位、日历、联系人、照片、设备 | 安卓权限、真实 provider、系统选择器及传感器 | 第三方账户规则和可用系统服务由手机控制；后台定位需要缓存或始终权限 |
| 提醒事项 | 应用持久任务库 + 通知调度 | 不等于 Apple/Google 的提醒账户同步；列表/重复规则可用 |
| 邮件、SMS、分享、PDF/文档 | 系统编辑器/分享页/查看器，真实二进制 URI 授权 | 用户确认发送；本应用不能断言是否已发送或指定外部客户端的发件账户 |
| 表格、弹窗、网页 | 安卓 UI、隔离网页、求值与导航回调 | 原生远程网页没有应用桥；浏览器远程页面受跨域政策限制 |
| 桌面组件 | 独立配置、完整画面、同运行器后台重跑、Chronometer | 15 分钟级系统刷新可能被推迟；计时器格式/字体采用安卓样式；锁屏使用桌面替代 |
| SFSymbol | 保留原创常用矢量并映射开放 MDI 字形 | 9155 标识中 2051 使用已标记的通用替代，未使用 Apple 图形/字体；可显式选择 SFSymbol.android(name) |
| iCloud、Siri、快捷指令 | 用户授权安卓 SAF/同步文件夹；桌面快捷方式、URI/x-callback | 不连接 Apple 云账户，不伪称运行在 Siri 中。大型二进制结果用文件/分享传递 |

系统数据 API 只在脚本实际请求时申请权限。测试使用模拟原生返回值验证字段、顺序、权限失败和取消；没有访问用户联系人、日历、相册、位置，也没有发送消息。

文件和 metadata 使用跨仓库实例共享锁；文件导入及云目录换入先检查未来快照容量，失败回滚；云写入失败保留本地副本和待上传记录。取消脚本会关闭对应视图/弹窗、停止语音与网络，并抑制权限弹窗授权后的继续执行；已完成的文件/provider 事务无法撤销。

顶部系统栏采用原生容器 Insets；源码编辑保持 textarea 输入/选择/中文输入法，语法高亮是同步镜像。320/360px、深色主题、横/纵滚动、补全、全屏预览和键盘处理经过浏览器验证，新版本手机系统栏仍待真机反馈。

详见 [系统契约](system-contract.md)、[呈现契约](presentation-contract.md)、[公开入口检查](api-surface-report.json)及应用内离线文档。
